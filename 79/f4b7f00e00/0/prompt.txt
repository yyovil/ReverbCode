**How the two hops work**

- **Hop 1 (cloud):** GitHub Actions calls `gh repo sync yyovil/ReverbCode --branch main --force` once a day at 00:00 UTC. This force-syncs your fork's `origin/main` to match `upstream/main`. The `GITHUB_TOKEN` is automatically available in Actions runners — no extra secret needed.

- **Hop 2 (local):** launchd wakes the shell script at midnight local time. The script runs `git pull --ff-only origin main` inside your repo. If your local `main` has unpushed commits ahead of `origin/main`, `--ff-only` makes git refuse with a non-zero exit and logs a clear error — it never rebases or destroys your work.

---

**Manual steps to activate the launchd job**

The plist is written but not loaded. When you are ready to activate it, run one of these (either works on macOS 10.15+):

```bash
# Modern (recommended, macOS 10.11+)
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.reverbcode.sync-main.plist

# Legacy alias (also works)
launchctl load ~/Library/LaunchAgents/com.reverbcode.sync-main.plist
```

To verify it loaded:
```bash
launchctl list | grep com.reverbcode.sync-main
```

To check logs after it fires:
```bash
tail -f ~/Library/Logs/reverbcode-sync-main.log
```

To unload it later:
